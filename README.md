# quietstudy

讓 [Shy Safari](https://www.shysafari.com/) 的設定和紀錄可以跨電腦使用的小工具。Shy Safari 只把資料存在每台電腦的瀏覽器裡，換電腦或教室電腦重開機就會不見。

- **[bookmarklet/](bookmarklet/)**：同步書籤（建議使用）。在 Shy Safari 頁面按一下書籤，就會載入你存在 Google 試算表裡的最新紀錄，之後每 30 秒自動保存，也有備份與還原。設定步驟見 [bookmarklet/README.md](bookmarklet/README.md)。
- **[index.html](index.html)**：手動匯出／匯入工具。不想設定試算表時，可以用它把紀錄存成檔案，再到另一台電腦匯入。
