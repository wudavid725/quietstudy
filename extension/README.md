# Shy Safari 自動同步（Chrome 擴充功能）

讓 [Shy Safari](https://www.shysafari.com/) 的設定和紀錄跟著你的 Google 帳號走。任何一台登入同一個帳號的 Chrome 打開 Shy Safari，都是最新的紀錄。

## 運作方式

- **自動載入**：打開 Shy Safari 時，如果雲端有比較新的紀錄，會自動載入並重新整理一次頁面。
- **自動保存**：網頁開著的時候每 30 秒檢查一次，有變動就上傳；切換分頁或關掉時也會再存一次。
- **自動備份**：每次覆蓋雲端紀錄前、載入另一台電腦的紀錄前，都會在這台電腦另存一份，最多保留 50 份。
- **兩台同時使用**：兩台電腦都改了紀錄時，Shy Safari 頁面上方會跳出提示，讓你選擇要用哪一份。兩份都會先存成備份，不會消失。
- 資料存在 Chrome 帳號的同步空間，不經過任何其他伺服器。

## 工具列圖示

把「Shy Safari 自動同步」釘選到工具列：按拼圖圖示，再按圖釘。

- 圖示出現**紅色驚嘆號**，代表同步有問題，點開看原因。
- 點開會顯示這台電腦和雲端最後同步的時間、使用空間和備份數量。
- **立即同步**：馬上保存一次。需要 Shy Safari 分頁開著。
- **管理備份**：打開備份頁面。

## 備份與還原

在備份頁面可以：

- 看到所有自動備份的時間和原因，按「還原」回到那個時間點。
- 按「下載」把任一份備份存成檔案。
- 按「下載目前的紀錄」自己保存一份。
- 按「從備份檔還原」匯入之前下載的檔案，用書籤工具匯出的檔案也可以。

還原之後，所有電腦都會改用還原後的版本。還原前的紀錄也會另存一份備份，按錯還能再還原回來。

自動備份只存在各自的電腦，不會同步。換電腦或重灌 Chrome 前，建議先下載一份備份檔。

## 安裝（每台電腦做一次）

擴充功能放在 Google 雲端硬碟裡，每台電腦都從同一個資料夾載入。之後有新版本時，雲端硬碟同步過來，擴充功能就會自己更新。

1. 確認 Chrome 已登入 Google 帳號，並在「設定 → 你和 Google → 同步處理」裡開啟同步，同步項目要包含「擴充功能」。
2. 安裝「Google 雲端硬碟電腦版」並登入同一個 Google 帳號。
3. 打開檔案總管裡的 Google 雲端硬碟，例如 `G:\我的雲端硬碟`，找到 `shysafari-sync` 資料夾。按右鍵，選「離線存取 → 可離線使用」，讓檔案一直存在這台電腦上。
4. 在網址列輸入 `chrome://extensions` 打開擴充功能頁。
5. 打開右上角的「開發人員模式」。
6. 按「載入未封裝項目」，選擇雲端硬碟裡的 `shysafari-sync` 資料夾。
7. 確認擴充功能的 ID 是 `jpagpbhiilhaoccfinomjekkcnldmmfh`。每台電腦的 ID 都一樣，資料才會互通。

## 自動更新

- 擴充功能每 2 分鐘檢查一次雲端硬碟資料夾，發現新版本就自己重新載入，不用進 `chrome://extensions`。
- 雲端硬碟還在同步、檔案不齊全時不會更新，等所有檔案都到齊才會更新。
- Shy Safari 開著的時候不會更新，以免上課到一半中斷同步。狀態視窗會顯示「新版本已下載」，關掉 Shy Safari 分頁後就會更新。
- 狀態視窗的「版本」可以看到目前執行的版本。
- 紀錄和備份在更新後都會保留。

如果雲端硬碟的磁碟代號或資料夾位置改了，Chrome 會找不到擴充功能，要回到 `chrome://extensions` 重新載入一次。

## 發布新版本（給維護的人）

修改 `extension` 資料夾後，在專案根目錄執行，路徑換成雲端硬碟裡的資料夾：

```bash
node tools/release.js "G:\我的雲端硬碟\shysafari-sync"
```

它會更新 `release.json`（所有檔案的清單和指紋），內容有變動時自動把版本號加一，再把檔案複製到雲端硬碟資料夾。各台電腦同步完成後會自己更新。

## 注意事項

- **新電腦第一次使用**：裝好後請先等一兩分鐘，讓 Chrome 把帳號資料下載完，再打開 Shy Safari。擴充功能也會等 1 分鐘才第一次上傳，避免新電腦的空白資料蓋掉雲端紀錄。
- **偵測不到同步開關**：擴充功能看得出 Chrome 有沒有登入帳號，但看不出「同步」有沒有打開。如果另一台電腦一直拿不到新紀錄，請檢查第 1 步的設定。
- **容量**：Chrome 同步空間上限約 100 KB，Shy Safari 的資料通常只有幾 KB。快滿時圖示會出現警告。
- **不要刪掉 `manifest.json` 裡的 `key`**：它決定擴充功能的 ID，刪掉後各台電腦的資料就不會互通。
- 只支援電腦版的 Chrome 和 Edge。手機和平板不能用。
