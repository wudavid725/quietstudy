Shy Safari 備份工具

Shy Safari 的設定和紀錄只存在每台裝置的瀏覽器裡。用這兩個書籤，把資料從一台裝置搬到另一台。

第一步：安裝書籤（每台裝置做一次）

把下面兩個按鈕拖曳到瀏覽器的書籤列。看不到書籤列的話，按 Ctrl + Shift + B（Mac 是 ⌘ + Shift + B）打開。

📤 匯出 Shy Safari 📥 匯入 Shy Safari

直接點這兩個按鈕不會有作用，要拖到書籤列，之後在 Shy Safari 網站上按。

第二步：在舊裝置匯出

  1. 打開 www.shysafari.com。
  2. 按書籤列上的「📤 匯出 Shy Safari」。
  3. 會下載一個 shysafari-backup-日期.json 備份檔，內容也會同時複製到剪貼簿。
  4. 把備份檔傳到新裝置，例如寄給自己、存到 Google 雲端硬碟或 LINE 傳給自己。

第三步：在新裝置匯入

  1. 在新裝置打開 www.shysafari.com。
  2. 按書籤列上的「📥 匯入 Shy Safari」。
  3. 選擇備份檔，或把匯出的文字貼進方框，按「匯入」。
  4. 頁面會重新整理，設定和紀錄就回來了。

匯入會覆蓋新裝置上原本的 Shy Safari 資料。這不是自動同步，每次換裝置前都要先在原本那台匯出最新的一份。
